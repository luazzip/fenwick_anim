# Fenwick Tree (Binary Indexed Tree) - Animación con Manim
Proyecto Final 1 - CS2023 Algoritmos y Estructuras de Datos

## Cómo reproducir
1. Instalar Python 3.10+ y FFmpeg
2. python -m venv venv && venv\Scripts\activate   (Mac/Linux: source venv/bin/activate)
3. pip install -r requirements.txt
4. manim -qh fenwick_anim.py S1_Intro S2_Update S3_Query S4_RangeQuery

Los videos quedan en media/videos/fenwick_anim/1080p60/
